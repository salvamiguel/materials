# Programa del módulo Azure Data Fundamentals (DP-900)

Este módulo prepara para la certificación **Microsoft Certified: Azure Data Fundamentals (DP-900)**. El recorrido parte de los fundamentos de cloud y Azure, cubre los tres pilares de datos del examen (relacional, no relacional y analítica) y cierra con una sesión de repaso integrado orientada a escenarios de examen.

## Dominios del examen DP-900

Pesos vigentes en la study guide oficial de Microsoft (actualizados a 21/07/2026):

| Dominio | Peso en el examen |
|---------|-------------------|
| Describe core data concepts | 25–30% |
| Identify considerations for relational data on Azure | 20–25% |
| Describe considerations for working with non-relational data on Azure | 15–20% |
| Describe an analytics workload on Azure | 25–30% |

---

## Requisitos previos

:::info Antes de empezar

- No se exige experiencia previa con Azure ni con bases de datos.
- Ayuda tener nociones básicas de qué es una base de datos y qué es un informe o dashboard.
- DP-900 es un examen conceptual: se valora entender los conceptos y saber elegir el servicio adecuado en un escenario, no la configuración práctica detallada.

:::
