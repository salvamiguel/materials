# Programa del módulo Azure AI Fundamentals (AI-901)

Este módulo prepara para la certificación **Microsoft Certified: Azure AI Fundamentals**, cuyo examen actual es **AI-901**. La certificación en sí no cambia de nombre ni desaparece: quien ya tenga AI-900 aprobado conserva su credencial sin hacer nada. Lo que cambió es el examen para obtenerla a partir de ahora.

---

## AI-900 vs AI-901: qué cambió

Microsoft anunció la evolución de la certificación el 15/04/2026 (última actualización del anuncio: 02/09/2026). El examen **AI-900** se retiró el **30/06/2026**; desde entonces, el único camino para obtener (o demostrar de nuevo) la certificación es **AI-901**, con disponibilidad general anunciada para junio de 2026 tras un periodo en beta.

| | AI-900 (antiguo) | AI-901 (nuevo) |
|---|---|---|
| Público | Principiantes técnicos o no técnicos | Principiantes técnicos que van a construir soluciones de IA |
| Qué evalúa | Entender conceptos de IA/ML e identificar cuándo usar cada servicio de Azure AI | Entender conceptos de IA **e implementar** soluciones con Microsoft Foundry |
| Conocimiento de código requerido | Ninguno | Sintaxis básica de Python |
| Nivel de conocimiento | Introductorio, enfoque clásico (describir servicios) | Aprovisionar recursos de Azure + implementar con Foundry y herramientas modernas de desarrollo de IA |
| Enfoque | "¿Qué es la IA?" | "¿Cómo construyo una app de IA con Foundry?" |

En la práctica, esto desplaza el peso del examen hacia lo práctico: un 55–60% de AI-901 evalúa **implementar** soluciones en Microsoft Foundry (desplegar un modelo, construir un cliente ligero, crear y probar un agente), frente al enfoque puramente descriptivo de AI-900.

:::info Fuente
Comparativa, fechas y cifras según el anuncio oficial de Microsoft: [Evolving the Microsoft Certified: Azure AI Fundamentals Certification](https://techcommunity.microsoft.com/blog/skills-hub-blog/evolving-the-microsoft-certified-azure-ai-fundamentals-certification/4494127) (Liberty Munson, Microsoft — publicado 15/04/2026, actualizado 02/09/2026).
:::

## Dominios del examen AI-901

Pesos vigentes en la study guide oficial de Microsoft (actualizados a 15/04/2026):

| Dominio | Peso en el examen |
|---------|-------------------|
| Identify AI concepts and capabilities | 40–45% |
| Implement AI solutions by using Microsoft Foundry | 55–60% |

---

## Requisitos previos

:::info Antes de empezar

- Conocimiento conceptual de las soluciones de IA en Azure (ideal: haber completado el módulo Azure Data Fundamentals).
- Nociones de sintaxis de Python: AI-901 incluye ejercicios prácticos ligeros en Microsoft Foundry.
- Familiaridad básica con recursos de Azure (grupos de recursos, regiones, suscripciones).

:::
